## LaterOn 能做什么

| 一键添加 | 按项目整理 | 随时继续浏览 |
| --- | --- | --- |
| 按 `Alt+1` 添加当前网页，按 `Alt+Shift+1` 添加当前窗口的所有标签页。 | 添加时选择项目，或者先放进“等待整理”；支持拖拽和多选移动。 | 在全屏界面管理，在浏览器侧栏继续浏览；再次打开网页时可以继续上次滚动位置。 |

LaterOn 会自动提取网页标题、摘要、封面和来源。已经打开的网页不会重复创建标签页，而是直接切换到现有页面。YouTube 按视频 ID 识别同一视频，短链接、播放列表和播放时间参数的差异不会重复打开，也不会重置已打开视频的播放位置。

## 1 分钟安装

> 本仓库是 [LaterOn](https://github.com/gaoyiiiii/LaterOn) 的**二次开发版本**。
> 安装包请从 [Releases](https://github.com/masterkimhank/LaterOn/releases/latest) 下载，
> 不要用上游的 `main.zip`——那是未改动的原版。改了哪些东西见 [CHANGELOG.md](CHANGELOG.md)。

LaterOn 目前通过开发者模式安装，主体功能支持 Chrome / Edge 121 及以上版本；网页翻译（`Alt+2`）依赖浏览器内置翻译接口，需要 Chrome 138 及以上。

1. [下载最新版 ZIP](https://github.com/masterkimhank/LaterOn/releases/latest) 并解压。
2. 打开 `chrome://extensions/`；Edge 使用 `edge://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压出来、包含 `manifest.json` 的那个文件夹。
5. 建议在扩展菜单中固定 LaterOn，点击图标即可打开侧栏。

## 日常使用

| 操作 | 方式 |
| --- | --- |
| 添加当前网页 | `Alt+1`，或网页右键菜单 |
| 添加当前窗口全部标签页 | `Alt+Shift+1` |
| 翻译当前网页 | `Alt+2`，在原文下方逐段插入中文译文，再按一次恢复 |
| 打开 LaterOn | 点击浏览器工具栏图标 |
| 搜索网页 | 地址栏输入 `lo`，按空格后输入关键词 |
| 在新标签页打开 | `⌘/Ctrl + 点击`文章卡片，或使用卡片右键菜单 |

快捷键可以在 `chrome://extensions/shortcuts` 中重新设置。

## 核心体验

- **等待整理**：没想好放在哪里时先添加，之后再统一归类。
- **收藏时的原标题**：网页标题后来被网站改写（视频下架、标题更换、页面变成“视频去哪了”）时，卡片保留你收藏那一刻的标题，并在标题下方用一行小字标出“收藏时：…”，方便回忆当时看的是什么。
- **搜索范围**：搜索框（全屏界面和侧栏都有）可在“全部”和“等待整理”之间切换——只想清理还没归类的收藏时，后者能把已归档到项目的网页排除掉。默认仍是“全部”，也就是在哪个项目里搜都能搜到别处。
- **全部项目首页**：用图板快速浏览所有项目，并直接新建项目。
- **侧栏继续浏览**：点击顶部“添加”将当前网页加入 LaterOn，已有网页显示“已添加”。切换浏览器标签页时，LaterOn 会自动定位到当前网页及其所属项目，并将横向项目栏中选中的项目滚入可视范围；阅读状态等数据刷新会保留当前选择的项目。
- **关闭已打开**：在项目头部点“关闭已打开”（侧栏就是筛选行最右边那颗小图标），可以把这个项目里仍在浏览器中打开的标签页一次性关掉（收藏不删）；设置里还能打开“删除网页时同时关闭对应标签页”，让清理收藏顺手收掉窗口。
- **项目归档**：归档项目会从普通项目列表和搜索中隐藏，可在全屏界面的“归档”中查看、搜索和恢复。归档中的已读网页仍按设置的期限自动清理；删除项目会同时永久删除其中的网页，操作前会确认。
- **阅读状态**：区分未读、在读和已读；已读内容默认 30 天后自动清理，可在设置中调整。
- **继续上次位置**：重新打开读过的网页时，由你决定是否回到上次滚动位置。
- **就地翻译**：按 `Alt+2` 在原文下方逐段插入中文译文，保留原文对照，再按一次恢复。翻译走浏览器内置的本机模型，网页内容不会上传到外部服务。首次使用需下载语言模型，浏览器版本过低时会提示升级（详见常见问题）。
- **批量处理**：多选后可移动、标记、删除，或在一个新窗口中打开。批量删除会先确认，取消时保留勾选，确认后删除本次选中的网页，并一并清理上传封面。添加、修改与删除使用后台最新数据提交；写入失败时保留原数据并提示重试。
- **多设备同步（可选）**：在设置里填一个支持 WebDAV 的网盘（坚果云、Nextcloud 等），几台电脑的收藏、项目、阅读状态和自制封面自动合并同步，不经过任何第三方服务器。默认关闭，账号密码只存在本机。
- **量大也不卡**：700 条左右收藏时，首屏渲染、滚动、搜索和高亮都做过针对性优化（屏外卡片延迟渲染、下拉按需填充、只更新受影响的卡片），比上游版本快约四成。
- **中英文界面**：可以在设置中切换中文 / English。

## 数据与隐私

- 网页、项目、阅读状态和设置保存在浏览器本地的 `chrome.storage.local` 中。
- LaterOn 不要求注册账号，也不会把添加的网页上传到 LaterOn 服务器。
- 设置页的“备份与恢复”可以把全部收藏导出成一个 JSON 文件，也能导入回来（按网址去重合并），换电脑或升级前建议导出一份。
- 多设备同步是可选项：开启后数据只会在你的浏览器和你自己填的网盘之间流动，不经过 LaterOn 的任何服务器。WebDAV 地址、账号和应用密码保存在本机 `chrome.storage.local`，不会写进同步文件或导出的 JSON。
- 数据按扩展 ID 隔离。这里的扩展 ID 是固定的（`ahfghclmnedaflabdpffhdbbdhjikjme`），解压到哪个文件夹、换哪台电脑装，都是同一个扩展，收藏跟着走。
- 例外只有一次：从 **1.73.0 及更早版本**升级上来时，ID 会从「按文件夹路径算出来的那个」变成上面这个固定值，浏览器会当成换了个扩展。所以升级前先导出一份，装好新版再导入（见下方「换文件夹后收藏全没了」）。
- 可以在设置页中清空全部本地网页数据。

## 常见问题

### 快捷键按下后没有反应

快捷键可能被系统或其他扩展占用。打开 `chrome://extensions/shortcuts`，为 LaterOn 换一个没有冲突的组合键。网页右键菜单不依赖快捷键，可以作为备用入口。

### 为什么有些页面不能添加？

Chrome 内部页面、扩展商店、浏览器内置 PDF 查看器等受保护页面不允许扩展注入内容。请切换到普通的 `http://` 或 `https://` 网页后再试。

### 按 `Alt+2` 没反应，或提示不支持本机翻译

网页翻译用的是浏览器内置的翻译接口（`Translator` / `LanguageDetector`，Chrome 138 及以上提供；Edge 视版本而定）。出现“当前 Chrome 不支持本机网页翻译，请升级浏览器”就是版本不够。另外首次翻译需要下载语言模型，设置里有闸门或网络受限时会停在这一步，界面上会显示下载进度。

### “加载已解压的扩展程序”提示找不到清单

请选择解压后直接包含 `manifest.json` 的文件夹，而不是它的上一级目录。

### 更新后界面没有变化

回到 `chrome://extensions/`，找到 LaterOn 并点击“重新加载”，然后重新打开侧栏或完整界面。

### 换文件夹后收藏全没了 / 怎么把收藏搬到另一台电脑

**新版本不再有这个问题**：扩展 ID 已经固定，文件夹改名、挪位置、换电脑解压到别的路径，装好都是同一个扩展，收藏直接就在。

只有一个例外 —— 从 **1.73.0 及更早版本**升级到这一版时，ID 会从「按文件夹路径算出来的那个」变成固定值，对浏览器来说等同于换了个扩展。这种情况下：

1. **升级前**，在旧版本的设置页「备份与恢复 → 导出网页」存一份 JSON；
2. 重新加载（或重新安装）新版扩展；
3. 在新版本的设置页用「导入网页」把它导回来。

顺序不能反：一旦先重新加载，旧 ID 下的数据就没有界面入口了（数据仍在浏览器 profile 的 `Local Extension Settings/<旧 ID>/` 里，但只能手工捞）。

导出的 JSON 包含收藏、项目、自定义封面、排序和上次阅读位置；导入时按网址去重合并，同一条网页不会变成两条。备份文件可以被手工修改，所以非 `http(s)` 的链接会在导入时被跳过。

### 侧栏出现在左边，能改到右边吗？

可以。侧栏方向由浏览器控制，在 Chrome 的“设置 → 外观 → 侧栏”中修改。

## 自己改代码

本仓库是二次开发分支，配套文档都在根目录：

- [FORK.md](FORK.md)：分支怎么用、一次改动的完整流程、怎么跟上游同步

- `node scripts/release.js`：发版一条龙，不带参数时只演练不发布
